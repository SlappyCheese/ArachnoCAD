Assembly Knot: The Clove Hitch

Why: Grips the main structural lines tightly under tension, preventing sags. Allows you to slide and fine-tune spacing before locking.

📚 Learn more about the Clove Hitch →

  1. Wrap the working end of the ring line over and around the spoke
  2. Cross back over the first wrap to form an "X"
  3. Pass the cord around the spoke one more time and tuck it underneath the "X"
  4. Pull both ends tightly to lock
